# Requerimiento

Construir una pantalla de login que permita ingresar email y contraseña además de un botón para ingresar.

Si el email y contraseña son correctos se deberá navegar a una pantalla de bienvenida que deberá tener un texto grande con forma de título dando la bienvenida y un texto más pequeño nombrando al usuario logueado. Ambos textos deberán estar centrados en la pantalla.

En el caso de que el email y/o contraseña son incorrectos mostrar un mensaje de error en la misma pantalla de login.
